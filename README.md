# Українська мова · 5 клас

Сайт для учнів 5S і 5L. Теорія за підручником **А. Онатій, Т. Ткачук «Українська мова. 5 клас» (2022)**, по 50 завдань з автоперевіркою в кожній темі, монети, звання, персонаж на 123 речі, спільна 3D-школа й кабінет учителя. Результати потрапляють у Google Таблицю.

Сайт статичний (HTML + JS без збирання). Дані зберігає Firebase (проєкт `grade-2addb`).

## Запуск: 4 кроки, які робить учитель

### 1. Правила бази даних (обов'язково, 2 хв)
Firebase Console → **Realtime Database → Rules**. Заміни весь текст вмістом файлу [`database.rules.json`](database.rules.json) і натисни **Publish**.
Поки цього не зроблено, база в режимі «Locked» і сайт не працюватиме.

### 2. Увімкнути сайт (GitHub Pages, 1 хв)
GitHub → репозиторій `5grade` → **Settings → Pages** → Source: *Deploy from a branch* → гілка з сайтом, тека `/ (root)` → **Save**.
За хвилину сайт буде на `https://vadym-kulyk.github.io/5grade/`.

### 3. Обліковий запис учителя
Відкрий `…/5grade/#/teacher`, введи пошту `badim1aaa@gmail.com`, придумай пароль і натисни **«Перший вхід: створити пароль»**.
Зроби це одразу після кроку 1: кабінет відкривається лише для цієї пошти.

### 4. Google Таблиця з результатами
1. Відкрий таблицю «Українська 5 — результати» на своєму Диску (або створи нову).
2. **Розширення → Apps Script**. Видали вміст `Code.gs` і встав код із [`apps-script/Code.gs`](apps-script/Code.gs).
3. ⚙️ **Налаштування проєкту** → увімкни «Показувати файл маніфесту appsscript.json». Відкрий `appsscript.json` і встав вміст [`apps-script/appsscript.json`](apps-script/appsscript.json).
4. Збережи, онови таблицю. З'явиться меню **📊 Українська 5 → Увімкнути автооновлення**. Google попросить дозволи: вони потрібні, щоб читати базу Firebase, оновлювати таблицю й зберігати PDF-звіти на Диску.

Таблиця оновлюється кожні 10 хвилин. Аркуші:
- **Дашборд**: графіки прогресу, активності й досвіду класів;
- **Спроби**: кожна спроба — окремий рядок із фільтрами, швидкістю й позначкою ⚡;
- **Учні**: звання, досвід, середній %, кількість спроб;
- **Прогрес**: теплова карта «учень × тема»;
- **Найдовші питання**: над якими завданнями учні думали найдовше.

Меню **«Звіт учня в PDF…»** зберігає звіт одного учня в теку «Звіти учнів» на Диску. Такий самий звіт є в кабінеті вчителя на сайті (кнопка «Звіт у PDF»).

## Що вміє сайт

| Для учня | Для вчителя |
|---|---|
| Профіль: клас, ім'я, PIN із 4 цифр | Огляд класу, теплова карта, активність |
| Теорія зі схемами для запам'ятовування, озвучення слів | Усі спроби з фільтрами та експортом CSV |
| 5 рівнів × 10 завдань, 9 типів завдань, пояснення після кожного | Найдовші й найскладніші питання |
| Монети, досвід, 10 звань, 16 значків, щоденна серія | Звіт учня у PDF |
| Магазин: 123 речі для персонажа, дорогі підказки (400 🪙) | Відкривати/закривати теми, дедлайни |
| Робота над помилками (повтор через день і через тиждень) | Моніторингові роботи й вхідна діагностика |
| 3D-школа з дверима до кожної теми, фрази, емоції, чат | Увімкнення чату, рейтингу; PIN-коди учнів |
| Захист від поспіху: попередження, пауза, без монет | Позначка ⚡ і швидкість у результатах |

## Як додати нову тему
1. Створи `content/topics/<id>.js` за зразком `apostrof.js`: теорія (`theory`), правила (`rules`), 5 рівнів по 10 завдань.
2. У `content/index.js` додай темі `ready: true`.
3. Перевір: `node tools/validate.mjs`.

Типи завдань: `choice`, `tf`, `multi`, `input`, `gap`, `match`, `sort`, `pick`, `order`.

## Налаштування
`js/config.js`: класи, ціни, нагороди, параметри захисту від поспіху.
